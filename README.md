# MantisBT - Plugins

Repositorio de plugins personalizados para [MantisBT](https://www.mantisbt.org/).

## Plugins disponibles

| Plugin | Versión | Descripción |
|--------|---------|-------------|
| [Attachments](plugins/Attachments/) | 3.2 | Formulario de carga de adjuntos personalizado con fecha de subida |
| [BugRelationPriority](plugins/BugRelationPriority/) | 2.0.3 | Muestra la prioridad de bugs relacionados en la tabla de relaciones |
| [CustomReports](plugins/CustomReports/) | 2.1.0 | Interfaz de reportes SQL personalizados |
| [ReminderManager](plugins/ReminderManager/) | 2.1.3 | Envío automático de recordatorios por email basado en campos de fecha |
| [TOTP](plugins/TOTP/) | 1.1.0 | Autenticación de doble factor (2FA) con TOTP |

## Instalación de plugins

1. Copiar la carpeta del plugin en `mantis/plugins/`
2. Ir a **Admin > Manage > Manage Plugins**
3. Hacer clic en **Install** junto al plugin deseado

## Requisitos

- MantisBT 2.0.0 o superior
- PHP 7.4.0+
