## Instalación / Installation

1. Copiar la carpeta del plugin en `mantis/plugins/` / Copy the plugin folder to `mantis/plugins/`
2. Ir a **Admin > Manage > Manage Plugins** / Go to **Admin > Manage > Manage Plugins**
3. Hacer clic en **Install** junto al plugin deseado / Click **Install** next to the desired plugin

## Requisitos / Requirements

- MantisBT 2.0.0 o superior / or higher
- PHP 7.4.0+
